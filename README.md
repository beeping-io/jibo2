## 📖 What is Jibo2?

Jibo2 is an independent reverse engineering and open source effort to revive the **Jibo social robot** (commercial 2017 version), whose servers were shut down in 2019, and turn it into a **modern AI-powered personal robotic assistant** with a **community skills marketplace** and **cross-platform mobile apps**.

Inspired by the MIT Media Lab Jibo Research Platform but developed independently, Jibo2 aims to be the open source foundation the community can reuse to bring their own Jibos back to life, extend them with custom skills, and build advanced social behaviors.

## 🚀 Quickstart

```sh
git clone https://github.com/beeping-io/jibo2.git
cd jibo2
cp .env.example .env        # fill in only the keys you need
./scripts/setup-dev.sh
```

The script installs managed Python 3.12, syncs the project env and
wires pre-commit hooks. See [`docs/dev-setup.md`](docs/dev-setup.md)
for the step-by-step breakdown, platform specifics (macOS + Linux)
and troubleshooting. [`.env.example`](.env.example) documents every
environment variable the project uses — placeholders are safe and
unfilled keys are harmless until their feature lands.
